# Raphael Hehl

Senior Software Engineer at Deutsche Bahn, working on the internal developer platform and now DB's AI agent platform. Based in Germany.

## Open source

- **Home Assistant:** contributions to core, frontend, docs and the iOS and Android apps. Code owner of the [UniFi Protect](https://www.home-assistant.io/integrations/unifiprotect/) and [UniFi Access](https://www.home-assistant.io/integrations/unifi_access/) integrations. UniFi Protect alone runs in over 25,000 installations.
- **UniFi libraries:** [uiprotect](https://github.com/uilibs/uiprotect), the Python library behind the UniFi Protect integration. I work on moving it from the private API to UniFi's official public API. Also contributed to py-unifi-access, aiounifi and unifi-discovery.
- **Other projects:** HAP-python (HomeKit camera support), AI-on-the-edge-device (webhooks), ESPHome, matter.js and EMS-ESP32. Smaller contributions to Prisma, Lighthouse CI, Hoppscotch and ncnn.
- **Own projects:** [integration-insights](https://github.com/RaHehl/integration-insights), CPU time and event loop blocks per Home Assistant integration.
- **Security research:** smart home devices and protocols, reported to vendors through coordinated disclosure.
